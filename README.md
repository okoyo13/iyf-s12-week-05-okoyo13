# JavaScript DOM Manipulation

## Overview

This repository contains my Week 05 JavaScript practice, focusing on DOM manipulation, event handling, interactive web pages, and form validation.

## Learning Objectives

- Select and manipulate HTML elements using JavaScript.
- Modify element content, attributes, and styles.
- Create, insert, move, clone, and remove DOM elements.
- Handle mouse, keyboard, and form events.
- Understand event bubbling and event delegation.
- Validate form input and display feedback to users.
- Build interactive applications using JavaScript.

## DOM Manipulation

The Lesson 9 exercises cover:

- **Element selection:** Selecting elements using DOM selection methods.
- **Content and attributes:** Reading and updating element content and attributes.
- **Styles and classes:** Changing element styles and applying CSS classes.
- **Element creation:** Creating and inserting new elements.
- **Element movement and removal:** Moving, removing, and cloning DOM elements.
- **DOM traversal:** Navigating between related elements in the document.

Practice file: `dom-practice.html`  
JavaScript file: `dom.js`

## DOM Events and Forms

The Lesson 10 exercises cover:

- **Event handling:** Responding to user interactions.
- **Mouse events:** Handling clicks and other mouse interactions.
- **Keyboard events:** Responding to keyboard input and shortcuts.
- **Event bubbling:** Understanding how events propagate through nested elements.
- **Event delegation:** Handling events from child elements through a parent element.
- **Form validation:** Checking user input and displaying error or success messages.

Practice file: `dom-practice.html`  
JavaScript file: `dom.js`

## Mini-Project: Interactive To-Do List

The To-Do List mini-project demonstrates DOM manipulation and event handling in a practical application.

Features include:

- Add new tasks.
- Mark tasks as completed or undo completion.
- Delete individual tasks.
- Filter tasks by all, active, or completed status.
- Display task statistics.
- Clear completed tasks.
- Edit tasks by double-clicking, with Enter to save and Escape to cancel.

Files:

- `index.html` — application structure.
- `styles.css` — application styling.
- `app.js` — application functionality.

## Daily Challenges

All five daily challenges are available from a single browser page.

Open `daily-challenges/index.html` to use the challenges.

### Day 1: Color Changer

- Generates a random hexadecimal color.
- Changes the color of all `h1`, `h2`, and `h3` headings when the button is clicked.

### Day 2: Dynamic Element Creator

- Adds a new numbered paragraph with each click.
- Provides a Delete button for each paragraph.

### Day 3: Image Remover

- Removes all sample images from the page.
- Includes a bonus hide/show feature for the images.

### Day 4: Content Copier

- Copies content from a source div into a target div.
- Includes a bonus drag-and-drop copying feature.

### Day 5: Dark Mode Toggle

- Toggles dark mode using a class on the `body` element.
- Uses CSS transitions to animate the background and text color changes.

Daily Challenge files:

- `daily-challenges/index.html`
- `daily-challenges/styles.css`
- `daily-challenges/script.js`

## How to Run the Projects

1. Clone or download this repository.
2. Open the repository folder in Visual Studio Code.
3. Open `index.html` to run the To-Do List mini-project.
4. Open `dom-practice.html` to run the DOM manipulation and event practice.
5. Open `daily-challenges/index.html` to run all five Daily Challenges on one page.

The HTML files can be opened directly in a web browser.
